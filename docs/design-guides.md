# Design comparisons

Choose a chart for a stated reading goal. These examples use original illustrative data and real VisDelta renders, inspired by the linked Datawrapper Academy guides. “Better” depends on the goal; discouraged choices remain available.

<p class="comparison-intro">Each pair tells one illustrative story twice, framed like a published chart: a headline that states the finding, a description of the data, the graphic, then notes and source. Each side includes its data and runnable code. Small multiples share a scale; explicit aggregations preserve totals. System hints inspect the same declarations. Direct endpoint and in-layer labels are currently unsupported, so those examples demonstrate the available legend alternative.</p>
