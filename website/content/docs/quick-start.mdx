This page builds the transition below: one bar chart whose y mapping changes
from revenue to profit. Use the controls to play it, reverse it or drag the
scrubber.

<LiveExample id="bar-remap" code={false} />

<Steps>
<Step>

### Declare one chart state

```ts
import { bar } from 'visdelta/bar';

const products = [
  { product: 'Hardware', revenue: 12, profit: 5 },
  { product: 'Software', revenue: 18, profit: 11 },
  { product: 'Services', revenue: 9, profit: 7 },
  { product: 'Support', revenue: 6, profit: 4 },
];

const revenue = bar(products)
  .x('product', { title: 'Product line' })
  .y('revenue', { title: 'Revenue ($M)' });
```

A state describes facts: its data, grain, encodings, layout, attention and
appearance. It is not an animation command, and creating it renders nothing.

</Step>
<Step>

### Branch to the next state

```ts
const profit = revenue.y('profit', { title: 'Profit ($M)' });
```

Chart states are immutable. `profit` reuses the declaration and data of
`revenue` and does not modify it, so both remain valid endpoints.

</Step>
<Step>

### Create one transition

```ts
import { transition } from 'visdelta/transition';
import 'visdelta/style.css';

const change = await transition(revenue, profit, { target: '#chart' });
```

Both endpoints must use the same chart type. VisDelta resolves both states,
loads the chart's renderer, matches corresponding marks and mounts a seekable
route into the target element. The target's previous contents stay in place
until the transition is ready.

</Step>
<Step>

### Supply progress

```ts
change.progress(0.42);                  // show one exact frame
change.play({ duration: 800 });         // animate 0 → 1
change.play({ from: 1, to: 0 });        // the same route, backward
change.pause();                         // stop at the current frame
change.destroy();                       // remove it when the view goes away
```

Progress is a number from `0` to `1`. Anything can supply it: a slider, a
button, scroll position, a gesture or an application timeline.

</Step>
</Steps>

## Connect a control

Controls stay outside the library. A range input is enough:

```html
<div id="chart"></div>
<input id="progress" type="range" min="0" max="1" step="0.01" value="0">
```

```ts
const slider = document.querySelector<HTMLInputElement>('#progress')!;
slider.addEventListener('input', () => change.progress(slider.valueAsNumber));
```

## Inspect what changed

Inspection is separate from playback. `delta()` is DOM-free:

```ts
import { delta } from 'visdelta/core';

delta(revenue, profit).stateChanges;
// [{ category: 'encoding', action: 'remap', channel: 'y' }]
```

The same result is available on the controller as `change.delta`. The seven
categories (Data, Grain, Encoding, Coordinate, Layout, Attention and
Appearance) describe endpoint differences. They are not a playback order.
