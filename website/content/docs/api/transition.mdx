---
title: transition()
description: Create one seekable transition between two states of the same chart type.
---

```ts
import { transition } from 'visdelta/transition';

function transition(
  from: Visualization,
  to: Visualization,
  options: TransitionOptions,
): Promise<VisualizationTransition>;
```

`transition()` resolves and loads both states' data, computes their
[`delta()`](/docs/api/core#delta), loads the chart's renderer and mounts a
seekable route into `options.target`. If setup fails, the target's previous
contents are restored.

```ts
const change = await transition(from, to, {
  target: '#chart',
  data: { sales: rows },
  height: 420,
  chartStyle: paperChartStyle,
});
```

`from` and `to` can be builder states or plain specs; plain specs need a
[registered chart module](/docs/concepts/chart-states#plain-specs).

## TransitionOptions

<auto-type-table path="src/transition.ts" name="TransitionOptions" />

### Canvas size

`width` and `height` are the outer size of the canvas (the SVG), margins included,
as in Observable Plot. Each takes a number of CSS pixels or `"auto"`.

| Option   | Omitted                                                                   | A number                                                          | `"auto"`                                                                                                  |
| -------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `width`  | The container's width, inside the figure's own border, re-fit on change.  | Exactly this wide. A narrower container overflows; nothing is clipped. | Exactly the container's content width, re-fit when it changes.                                            |
| `height` | The chart's own height (an authored `height`, else 500).                  | Exactly this tall; overrides the chart's own height.              | Exactly the container's content height, re-fit when it changes. The container needs a height of its own.  |

```ts
// Fixed: always 640 × 360, whatever the container is.
await transition(from, to, { target: '#chart', width: 640, height: 360 });

// Fit: follow the container, e.g. a resizable or floating panel with a height.
await transition(from, to, { target: '#panel', width: 'auto', height: 'auto' });
```

A chart is wrapped in a figure that a theme may give a border. A number is always
the canvas itself, so that chrome sits outside it. A title, a subtitle and a top
legend also sit outside the canvas, above it, and never count toward `width` or
`height`. For `"auto"` the figure's border on that axis gives way and the heading
and legend take their room from the container, so the canvas fills exactly what
is left and nothing overflows the container. The legend is a second
`<svg class="vd-legend-svg">` that exists only while there is a legend, after the
canvas in the document, so `querySelector('svg')` is still the canvas. A
transition holds the tallest legend block of the pair, so the canvas never moves.
A style with `legendPosition: 'right'` keeps its legend inside the canvas.

`height: 'auto'` reads the room the container gives the chart. A container with
no height of its own (its height comes from its content) gives none, so the
chart keeps its own height instead of growing in a loop. Give the container a
fixed height, or make it a flex or grid track. An explicit `height` also
releases the view's default `min-height`, so it is the canvas height rather
than a floor under it.

`target` is a CSS selector or an element. The transition owns its contents until
`destroy()`.

## VisualizationTransition

The returned controller.

<auto-type-table path="src/transition.ts" name="VisualizationTransition" />

| Method                     | Returns     | Notes                                                                     |
| -------------------------- | ----------- | ------------------------------------------------------------------------- |
| `progress(value)`          | controller  | Pauses playback and draws one frame. Finite values clamp to `[0, 1]`.      |
| `play(options?)`           | controller  | Animates from `from` to `to`; see `PlayOptions`.                           |
| `pause()`                  | controller  | Stops playback at the current frame.                                      |
| `resize(options?)`         | controller  | Recompiles at the container's size and current theme, keeping progress. `{ width, height }` change the requested canvas size; a dimension left out keeps its request. |
| `stageCount()`             | `number`    | Serial route stages VisDelta planned for the pair (at least 1). They split progress equally, and `play({ duration })` gives each stage `duration` ms, so a full play lasts `stageCount() × duration`. |
| `destroy()`                | `void`      | Stops playback, disconnects observers and removes the chart.              |

Pair controllers observe their container's width and resize automatically.

## PlayOptions

<auto-type-table path="src/transition.ts" name="PlayOptions" />

```ts
change.play();                       // 0 → 1
change.play({ from: 1, to: 0 });     // reverse
change.play({ from: change.value });  // resume
```

## Errors

| Message                                              | Cause                                    |
| ---------------------------------------------------- | ---------------------------------------- |
| `transition() requires two states of the same chart type.` | Endpoints from different chart families |
| `VisDelta needs a target: …`                         | `options.target` is missing              |
| `VisDelta target not found: …`                       | The selector matched no element          |
| `transition(): missing dataset "…"`                  | A named source is not in `options.data`  |
| `progress must be a finite number.`                  | `progress()` received `NaN` or `Infinity` |
| `duration must be a finite non-negative number.`     | Invalid `play({ duration })`             |
| `This transition has been destroyed.`                | The controller was used after `destroy()` |

See [Troubleshooting](/docs/guides/troubleshooting) for fixes.
