Every method returns a **new** state; none mutates the receiver. Option bags not
listed here are documented on the linked pages.

## Factories

```ts
bar(data?): BarState        // visdelta/bar
line(data?): LineState      // visdelta/line
area(data?): AreaState      // visdelta/area
point(data?): PointState    // visdelta/point
unit(data?): UnitState      // visdelta/unit
pie(data?): PieState        // visdelta/pie
```

`data` is rows, `{ values }`, `{ url, type? }` or `{ name }`; see
[Data sources](/docs/concepts/data-and-transforms#data-sources).

## Shared methods

Available on every chart state. See [Chart states](/docs/concepts/chart-states)
and [where, highlight and focus](/docs/concepts/selection).

```ts
.data(source)
.x(field, options?)
.y(field, options?)
.channel(name, field, options?)
.color(valueOrField, options?)
.size(field, options?)
.key(fieldOrFields)
.datumKey(fieldOrFields)
.tooltip(fieldOrFields)
.sort(field, 'ascending' | 'descending')
.where(selector)
.highlight(selector, { opacity? })
.focus(selector)
.reset()
.axis(config)
.title(text | null)
.subtitle(text | null)
.transition({ duration?, ease?, stagger? })
.repeat(field, { direction?, scales?, columns?, gap?, minWidth?, autoHeight?, minHeight? })
.rows(source?)   // → tidy rows after transforms
.toSpec()        // → detached view spec
```

Unit compact layout bindings and chained setters are equally supported:
`.layout('beeswarm', { x: 'length' })` and `.layout('beeswarm').x('length')`
write the same state. The last explicit binding replaces the complete channel;
omitted layout options preserve it. See [Unit](/docs/charts/unit).

### Title and subtitle

`.title(text)` and `.subtitle(text)` put a heading above the chart, in the
figure and outside the canvas, so it never changes the canvas's `width` or
`height`. Blank text and `null` remove it. They are fixed styling: a change is
Appearance `restyle` with property `title` or `subtitle`.

```ts
bar(rows).x('state').y('population').title('Residents under 10').subtitle('US Census, 2020');
```

<LiveExample id="bar-title" />

In a transition the old text fades out over the first half and the new text
fades in over the second, driven by the pair's progress, so reverse playback
shows the same frames backward. The heading's room follows the same progress, so
the first frame is the old state drawn on its own and the last frame the new one,
and a fixed-height canvas only slides in between. With `height: 'auto'` the
canvas uses the remaining container height as the heading opens or closes.
Sequence endpoints use their own heading space. Headings are not part of
route planning, so a grain change that also changes the title keeps its
automatic intermediate states.

### Channel labels and figure titles

Use `.title(text)` and `.subtitle(text)` for the whole figure. Use `label` in
channel options for the display name of a field, for example
`.x("hp", { label: "Horsepower" }).title("Cars")`. Channel `title` has been
replaced by `label`; update existing channel configurations, including tooltip
fields and Bar rollup/breakdown measure labels. This does not change figure
headings or their transition behavior. An omitted label defaults to the field's
readable name. Compact Unit layout bindings also accept `label` in their channel
objects and remain equivalent to chained `.x()` / `.y()` declarations.
